## PART 1: Project-Specific Viva Voce Questions (25 Questions)

1. **What is NetSentry AI?**  
   *Answer:* An academic research and engineering platform that analyzes bidirectional network flow telemetry (NetFlow/IPFIX) using 11 machine learning algorithms, models physical network stress, and provides an interactive Streamlit SOC dashboard.  
   *Ref:* `src/netsentry/`

2. **Why evaluate network flows rather than raw packet payloads?**  
   *Answer:* Over 85% of modern traffic is encrypted with TLS/HTTPS. Flow metadata (packet counts, durations, byte rates, TCP flags) allows high-throughput classification without decrypting payloads or violating user privacy.  
   *Ref:* `src/netsentry/pcap/flow_extractor.py`

3. **Which model is your champion and why?**  
   *Answer:* LightGBM. It achieved the highest holdout Macro-F1 (0.9892) with the lowest FPR (1.59%) and sub-millisecond inference latency (0.0156 ms/flow), outperforming Random Forest while consuming 77% less disk footprint (344 KB vs 1.5 MB).  
   *Ref:* `artifacts/phase6_experiment_results.json`

4. **What is the canonical 5-tuple in NetSentry AI?**  
   *Answer:* (Source IP, Destination IP, Source Port, Destination Port, Layer 4 Protocol).  
   *Ref:* `src/netsentry/pcap/flow_extractor.py#L31-L45`

5. **How does your PCAP parser handle bidirectional traffic?**  
   *Answer:* It orders endpoint sockets lexicographically: `if (src_ip, sport) <= (dst_ip, dport)`. Forward and backward packets are merged into a single connection record.  
   *Ref:* `src/netsentry/pcap/flow_extractor.py#L190-L197`

6. **What session timeout is used in flow reconstruction?**  
   *Answer:* A 120-second idle timeout (`idle_timeout_sec = 120.0`). Inactive sessions exceeding this duration are finalized and closed.  
   *Ref:* `src/netsentry/pcap/flow_extractor.py#L96`

7. **How many automated tests exist in your test suite?**  
   *Answer:* 63 automated tests, 100% passing in ~15.6 seconds.  
   *Ref:* `tests/`

8. **What is the difference between the 8-feature demo model and the 77-feature CIC-IDS2017 research model?**  
   *Answer:* The 8 canonical features represent standard flow metrics for offline PCAP ingestion. The 77-feature model evaluates subflow bytes, inter-arrival times, and window statistics generated by CICFlowMeter.  
   *Ref:* `docs/PHASE9_RESEARCH_AUDIT.md#L5`

9. **What datasets were evaluated?**  
   *Answer:* Canadian Institute for Cybersecurity CIC-IDS2017 and Australian Centre for Cyber Security UNSW-NB15.  
   *Ref:* `data/sample/`

10. **What is Concept Inversion in your generalization experiments?**  
    *Answer:* Flow duration correlates positively with attack traffic in CIC-IDS2017 (volumetric DoS floods), but correlates negatively in UNSW-NB15 (microsecond exploit probes).  
    *Ref:* `src/netsentry/research/generalization_strategies.py#L313-L325`

11. **How much did cross-dataset performance degrade between CIC-IDS2017 and UNSW-NB15?**  
    *Answer:* Macro-F1 collapsed by 66.82% (from 0.9488 in-domain to 0.3148 cross-domain).  
    *Ref:* `artifacts/phase6_experiment_results.json#L411`

12. **How did you fix Concept Inversion?**  
    *Answer:* Using Joint Multi-Domain Training (Strategy 7), which exposed the trees to mixed partitions, recovering cross-domain Macro-F1 to 0.8932.  
    *Ref:* `artifacts/phase6_experiment_results.json#L491-L500`

13. **What happened when 5% measurement jitter was added?**  
    *Answer:* LightGBM Macro-F1 collapsed from 0.9892 to 0.6617, flipping 33.12% of test predictions and causing 405 malicious flows to flip to benign.  
    *Ref:* `artifacts/phase7_robustness_results.json#L88-L101`

14. **Why are tree models brittle to continuous measurement jitter?**  
    *Answer:* Trees create orthogonal axis-aligned step functions that tightly envelop deterministic scripted attack intervals. Small jitter pushes samples across the threshold into the benign partition.  
    *Ref:* `docs/ROBUSTNESS_TESTING.md#L164`

15. **What happened under Enterprise Jumbo Frames (MTU 9000)?**  
    *Answer:* Scaling packet lengths to 8,960 bytes dropped Macro-F1 to 0.6639 (33.28% flips) because attack flows resembled large enterprise storage transfers.  
    *Ref:* `artifacts/phase7_robustness_results.json#L409-L422`

16. **What happened under 100 Gbps line-rate bursts?**  
    *Answer:* Macro-F1 remained stable at 0.9850 (only 0.56% flips) due to monotonic threshold saturation.  
    *Ref:* `artifacts/phase7_robustness_results.json#L436-L449`

17. **What is your Safe Failure Quarantine Policy?**  
    *Answer:* Division by zero (`+Inf`/`-Inf`) or $>80\%$ missingness assigns `prediction = -1` (`QUARANTINE_NON_FINITE`), isolating corrupt inputs rather than reporting them as benign.  
    *Ref:* `src/netsentry/predict.py#L86-L115`

18. **How does your IP privacy masking work?**  
    *Answer:* It masks IPv4 host octets (`192.168.1.***`) and IPv6 endpoints (`2001:db8:85a3:****`), preserving subnet routing topology while anonymizing hosts.  
    *Ref:* `src/netsentry/utils/logging.py#L43-L53`

19. **What secret scrubbing is implemented?**  
    *Answer:* Regex scrubbers redact passwords, bearer tokens, AWS keys (`AKIA...`), and student Windows usernames (`[USER_DIR]/`).  
    *Ref:* `src/netsentry/utils/logging.py#L55-L68`

20. **What file upload protections exist in the Streamlit UI?**  
    *Answer:* A strict 50 MB file size limit and streaming Scapy iterator (`max_packets = 10000`).  
    *Ref:* `app/views/traffic_analyzer.py#L79-L81`

21. **How are temporary PCAP uploads cleaned up?**  
    *Answer:* Files are created via `tempfile.NamedTemporaryFile` and deterministically unlinked in `finally` blocks upon completion or error.  
    *Ref:* `app/views/traffic_analyzer.py#L104-L111`

22. **What does the local explainer compute?**  
    *Answer:* It computes $z$-score deviations of incoming flow features against baseline normal medians, generating plain-English SOC analyst narratives.  
    *Ref:* `src/netsentry/explainability/local_explainer.py`

23. **What was the result of unseen attack evaluation on DoS?**  
    *Answer:* Supervised Random Forest had 0.0% recall, while unsupervised Isolation Forest detected 66.79% of novel DoS attacks without labels.  
    *Ref:* `artifacts/phase6_experiment_results.json#L316-L330`

24. **What was the result of unseen attack evaluation on PortScan?**  
    *Answer:* Both supervised (0.0%) and unsupervised (0.0%) failed completely because low-packet scans geometrically overlap with normal baseline traffic.  
    *Ref:* `artifacts/phase6_experiment_results.json#L331-L345`

25. **What is the local batch scoring throughput?**  
    *Answer:* Over 15,240 flows/second on standard 4-core hardware.  
    *Ref:* `artifacts/phase8_performance_results.json`

## PART 2: Machine Learning Questions (15 Questions)

26. **What is the difference between bagging and boosting?**  
    *Answer:* Bagging (Random Forest) trains independent trees in parallel on bootstrap samples to reduce variance. Boosting (LightGBM) trains sequential trees where each tree corrects errors of previous trees to reduce bias.

27. **Why use scikit-learn Pipelines?**  
    *Answer:* Pipelines chain preprocessing (imputation, scaling) and modeling, ensuring transformers are fitted strictly on training folds during cross-validation without data leakage.  
    *Ref:* `src/netsentry/models/factory.py`

28. **What is the difference between StandardScaler and RobustScaler?**  
    *Answer:* StandardScaler uses mean and standard deviation (sensitive to DDoS outliers). RobustScaler centers on median and scales by Interquartile Range (IQR), insulating normal distributions from extreme bursts.

29. **What is the Base-Rate Fallacy in binary classification?**  
    *Answer:* When target class prevalence is very low, even a small false positive rate causes the vast majority of positive predictions to be false alarms.

30. **Explain Macro-F1 vs Weighted-F1.**  
    *Answer:* Macro-F1 computes the unweighted arithmetic mean of F1 scores across classes, giving equal weight to minority attacks. Weighted-F1 weights each class by support, allowing majority benign traffic to dominate.

31. **Why does LinearSVC require CalibratedClassifierCV?**  
    *Answer:* LinearSVC optimizes hinge loss and does not output probabilities. CalibratedClassifierCV applies Platt scaling (sigmoid fitting) to produce calibrated probability outputs.  
    *Ref:* `src/netsentry/models/factory.py#L155-L167`

32. **How does Isolation Forest isolate anomalies?**  
    *Answer:* It constructs random binary partition trees. Sparse geometric outliers require fewer random splits to isolate, resulting in shorter average tree path lengths.

33. **What is contamination in Isolation Forest?**  
    *Answer:* The expected proportion of outliers in the dataset, used to set the decision threshold on anomaly scores.

34. **Why is cross-validation better than a single holdout split?**  
    *Answer:* $k$-fold cross-validation evaluates variance across $k$ distinct partitions, reducing sampling bias and proving stability.

35. **What is target leakage?**  
    *Answer:* When features contain information directly derived from or correlated with the ground truth label that will not be available during live inference.

36. **How does threshold calibration affect precision and recall?**  
    *Answer:* Raising $\tau$ increases precision and decreases false alarms (conservative), while lowering $\tau$ increases recall and catches more attacks (high security).

37. **What is the difference between L1 and L2 regularization?**  
    *Answer:* L1 (Lasso) adds absolute coefficient penalties and induces sparsity. L2 (Ridge) adds squared penalties and shrinks weights smoothly.

38. **Why are tree models invariant to monotonic feature scaling?**  
    *Answer:* Trees split on rank order ($x > \theta$). Applying a monotonic transformation (like log or standard scaling) preserves the ordering of samples.

39. **What is the difference between class_weight='balanced' and standard training?**  
    *Answer:* Balanced class weighting penalizes classification errors inversely proportional to class frequencies, preventing majority classes from dominating split loss.

40. **What causes covariate shift in network ML?**  
    *Answer:* When the input feature distribution $P(X)$ changes between training and production environments while the conditional probability $P(Y|X)$ remains unchanged.

## PART 3: Data Communication and Networking (DCN) Questions (15 Questions)

41. **What is the difference between TCP and UDP?**  
    *Answer:* TCP is connection-oriented, reliable, and byte-stream based with 3-way handshakes and retransmissions. UDP is connectionless, unreliable, and datagram-based without flow control.

42. **What occurs during the TCP 3-way handshake?**  
    *Answer:* Client sends SYN; Server responds with SYN-ACK; Client replies with ACK to establish connection.

43. **How does a SYN flood attack work at the transport layer?**  
    *Answer:* Attacker sends thousands of spoofed SYN packets without responding to SYN-ACKs, filling the server's half-open connection backlog queue (SYN queue).

44. **What is the difference between an IPv4 header and an IPv6 header?**  
    *Answer:* IPv4 uses 32-bit addresses with a variable header (20-60 bytes). IPv6 uses 128-bit addresses with a fixed 40-byte base header and extension headers.

45. **What is an MTU and what is its default Ethernet value?**  
    *Answer:* Maximum Transmission Unit; maximum L3 packet size transferable without fragmentation. Standard Ethernet is 1,500 bytes; Jumbo frames are 9,000 bytes.

46. **What is an IP fragment and why does it pose security challenges?**  
    *Answer:* When a packet exceeds link MTU, routers split it into fragments. Only the first fragment contains Layer 4 port headers; subsequent fragments lack port context.

47. **What is NetFlow / IPFIX?**  
    *Answer:* Cisco and IETF standards for exporting Layer 3/4 network flow statistical records from routers and switches.

48. **What does TCP RST flag indicate?**  
    *Answer:* Reset flag; immediately aborts a connection due to an unhandled packet or closed port.

49. **What does TCP FIN flag indicate?**  
    *Answer:* Finish flag; initiates graceful unidirectional connection teardown.

50. **What is a PCAP file?**  
    *Answer:* Packet Capture file format (Libpcap standard) containing global capture headers followed by raw packet records with microsecond timestamps and raw bytes.

51. **What is the difference between PCAP and PCAPNG?**  
    *Answer:* PCAP is legacy single-interface capture format. PCAPNG (Next Generation) supports multiple interfaces, comments, and nanosecond timestamp resolution.

52. **What are the layers of the OSI model?**  
    *Answer:* Physical, Data Link, Network, Transport, Session, Presentation, Application.

53. **What layer do network flow features operate on?**  
    *Answer:* Layer 3 (Network) and Layer 4 (Transport).

54. **What is jitter in network engineering?**  
    *Answer:* Packet Delay Variation (PDV); statistical variance in packet transit delay across a network path.

55. **Why can't metadata NIDS inspect TLS 1.3 payloads?**  
    *Answer:* TLS 1.3 encrypts all application data and handshake extension headers using ephemeral Diffie-Hellman keys.

## PART 4: Python & Software Engineering Questions (10 Questions)

56. **What is the purpose of `__pycache__` and `.pyc` files?**  
    *Answer:* Cached compiled Python bytecode to accelerate subsequent import startup.

57. **How does Python's `joblib.dump` serialize scikit-learn models?**  
    *Answer:* It serializes Python objects and large NumPy numerical arrays efficiently using disk persistence.

58. **What security risk is associated with `joblib.load()`?**  
    *Answer:* Unpickling untrusted files can execute arbitrary system commands (`__reduce__` exploit). NetSentry AI restricts loading strictly to local repository artifacts.

59. **Why use `argparse` in CLI scripts?**  
    *Answer:* Standard library module for parsing command-line flags, providing automated help menus, type casting, and default parameters.  
    *Ref:* `src/netsentry/predict.py`

60. **What is the Global Interpreter Lock (GIL) in CPython?**  
    *Answer:* A mutex preventing multiple native OS threads from executing Python bytecodes simultaneously, restricting CPU-bound threading to a single core.

61. **How does NetSentry AI achieve parallel model training?**  
    *Answer:* By passing `n_jobs=-1` to scikit-learn and LightGBM, which utilize multi-process C/OpenMP worker threads outside the Python GIL.

62. **What is the difference between `deepcopy()` and shallow copy (`copy()`)?**  
    *Answer:* Shallow copy copies object references; deepcopy recursively duplicates all nested objects and dictionaries.

63. **Why use `tempfile.NamedTemporaryFile` for uploaded captures?**  
    *Answer:* It generates unique cryptographically random file paths in the operating system's temporary directory, preventing path collisions and path traversal attacks.  
    *Ref:* `app/views/traffic_analyzer.py#L82`

64. **What is the difference between a unit test and an integration test?**  
    *Answer:* Unit tests test individual functions or classes in isolation. Integration tests test multi-component end-to-end workflows (e.g. PCAP upload $\to$ flow aggregation $\to$ inference $\to$ alert).

65. **Why use virtual environments (`venv`)?**  
    *Answer:* To isolate project dependencies and Python packages, preventing version conflicts with the global operating system Python environment.

## PART 5: Challenging Interviewer Follow-Ups (10 Questions)

66. **"If LightGBM achieved 0.989 F1, why not deploy it directly to an edge router?"**  
    *Answer:* Clean holdout F1 does not guarantee edge stability. In Phase 7, 5% measurement jitter caused a 33% prediction flip rate, and in low-prevalence live networks, 94% of alerts are false alarms. Deploying it directly would overwhelm analysts.

67. **"Could an attacker evade your model by padding packets?"**  
    *Answer:* Yes. Because our model relies heavily on `average_packet_size` and byte rates, an attacker adding dummy padding or junk bytes can alter the flow geometry to match legitimate file downloads.

68. **"Why didn't you use deep learning (LSTMs or Transformers)?"**  
    *Answer:* Tabular network flow features lack sequential language semantics. Tree ensembles (LightGBM) consistently outperform deep learning on tabular data while requiring 100x lower training compute and achieving sub-millisecond inference (0.016 ms).

69. **"How do you handle zero-day attacks that your model has never seen?"**  
    *Answer:* We deploy a hybrid defense: supervised LightGBM handles known attack signatures, while unsupervised Isolation Forest isolates high-volume volumetric zero-days.

70. **"Why not train exclusively on UNSW-NB15?"**  
    *Answer:* Training on a single dataset creates single-environment overfitting. Evaluating on both CIC-IDS2017 and UNSW-NB15 revealed domain shift and proved the value of joint multi-domain training.

71. **"What happens if an attacker crafts an infinite rate flow?"**  
    *Answer:* Division by zero yields `+Inf`. In `src/netsentry/predict.py`, non-finite inputs are trapped and quarantined (`QUARANTINE_NON_FINITE`), preventing arbitrary classification.

72. **"Why use Scapy instead of TShark or tcpdump?"**  
    *Answer:* Scapy is native Python, requiring zero external binary installations on Windows/Linux, making the project 100% self-contained and reproducible for students and interviewers.

73. **"Is your pipeline deterministic?"**  
    *Answer:* Yes. All data splitting, pipeline fitting, and evaluations use fixed seeds (`random_state = 42`). Phase 5 verified 5-seed stability across seeds 42, 101, 7, 2024, and 999.

74. **"Why does Decision Tree have higher F1 than Logistic Regression?"**  
    *Answer:* Network flow boundaries are highly non-linear (e.g. attacks occur when duration is short AND packet rate is high). Linear models cannot learn multi-feature conjunctions without polynomial features.

75. **"What would happen if your model ran on 100 Gbps live wire feeds?"**  
    *Answer:* Python Scapy would experience massive packet queue drops. Live 100 Gbps deployment requires kernel bypass drivers like DPDK or eBPF/XDP ring buffers.

## PART 6: Limitations, Reliability & Ethics (5 Questions)

76. **"What are the top three limitations of NetSentry AI?"**  
    *Answer:* 1. Blind to malicious payloads inside encrypted TLS 1.3 tunnels. 2. Sensitive to physical clock jitter. 3. Python interpreter throughput limits live wire-speed capture.

77. **"Is NetSentry AI a production firewall?"**  
    *Answer:* No. It is an educational and research prototype for offline packet analysis, flow reconstruction, and ML stress-testing.

78. **"How do you protect student privacy in shared logs?"**  
    *Answer:* Automatic regex sanitizers redact local user profile directories (`C:\Users\username\` $\to$ `[USER_DIR]/`) and mask IP host octets (`192.168.1.***`).

79. **"What are the ethical responsibilities when capturing network packets?"**  
    *Answer:* Wiretapping laws require explicit written authorization before capturing or analyzing packets from any network you do not own.

80. **"What is your key takeaway from this project as an engineering student?"**  
    *Answer:* Real-world machine learning engineering is not about chasing 99% accuracy on clean benchmark splits; it is about understanding data distributions, domain shift, physical sensor noise, and building safe failure architectures.
