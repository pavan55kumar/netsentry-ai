# NetSentry AI — Cross-Dataset Generalization & Domain Shift Report

## 1. The Generalization Crisis in Machine Learning NIDS

In academic literature, hundreds of papers claim $> 99.5\%$ accuracy for intrusion detection models trained on standard benchmark datasets (e.g. KDD99, NSL-KDD, CIC-IDS2017). However, when enterprise security teams deploy these identical models onto live corporate networks, detection performance collapses catastrophically, producing massive false alarm rates or failing to intercept novel attacks.

This phenomenon is known as the **Generalization Crisis**, caused by **Domain Shift**:
$$P_{\text{train}}(\mathbf{X}, y) \neq P_{\text{deploy}}(\mathbf{X}, y)$$

Rather than evaluating models solely on random splits from a single capture environment, NetSentry AI implements an automated **Cross-Dataset Generalization Workbench** (`netsentry.research.cross_dataset`) to scientifically evaluate transferability between **CIC-IDS2017** and **UNSW-NB15**.

---

## 2. Mathematical Taxonomy of Domain Shift

Domain shift in network flow data manifests in two distinct forms:

### 2.1. Covariate Shift ($P_{\text{source}}(\mathbf{X}) \neq P_{\text{target}}(\mathbf{X})$ while $P(y \mid \mathbf{X})$ is invariant)
The marginal feature distributions differ across capture environments, even though the fundamental concept of an attack remains unchanged:
- **CIC-IDS2017**: Captured across an emulated office testbed at UNB with typical North American MTU (1,500 bytes) and background traffic generated by B-Profiles (user behavior modeling HTTP/HTTPS, SSH, FTP).
- **UNSW-NB15**: Captured in the ACCS Cyber Range Lab using IXIA PerfectStorm hardware traffic generators, resulting in distinct packet burst distributions, different average packet sizes, and higher synthetic flow frequencies.
- **Result**: A decision tree threshold trained on CIC-IDS2017 (e.g., `packet_rate > 350`) may classify normal high-bandwidth IXIA video streaming in UNSW-NB15 as a volumetric DoS attack.

### 2.2. Concept Shift ($P(y \mid \mathbf{X})$ changes across environments)
The relationship between flow features and ground truth changes:
- In an enterprise datacenter, a sudden spike in inter-server TCP connections on port 3306 indicates database replication (benign).
- In an office workstation VLAN, the exact same connection spike indicates lateral network worm propagation (malicious).

## 3. Semantic Feature Harmonization Engine

Because CIC-IDS2017 (78 features generated by CICFlowMeter) and UNSW-NB15 (45 features generated by Argus/Bro) employ incompatible column names and measurement scales, NetSentry AI defines a **Common Semantic Flow Feature Schema**:

$$\mathcal{F}_{\text{shared}} = \{\text{duration\_sec}, \text{fwd\_packets}, \text{bwd\_packets}, \text{byte\_rate}, \text{packet\_rate}, \text{avg\_packet\_size}\}$$

### Feature Alignment Mapping Table:
| Semantic Feature | CIC-IDS2017 Mapping | UNSW-NB15 Mapping | Unit |
| :--- | :--- | :--- | :--- |
| `duration_sec` | `Flow Duration / 1,000,000.0` | `dur` | Seconds ($s$) |
| `fwd_packets` | `Total Fwd Packets` | `spkts` | Packet count |
| `bwd_packets` | `Total Backward Packets` | `dpkts` | Packet count |
| `byte_rate` | `Flow Bytes/s` | `(sbytes + dbytes) / dur` | Bytes / sec |
| `packet_rate` | `Flow Packets/s` | `rate` | Packets / sec |
| `avg_packet_size` | `Average Packet Size` | `(sbytes + dbytes) / (spkts + dpkts)` | Bytes / packet |
| `label` | $\text{Label} \neq \text{"BENIGN"}$ | $\text{attack\_cat} \neq \text{"Normal"}$ | Binary (0 / 1) |

## 4. Empirical Cross-Domain Generalization Findings

Using the standardized semantic feature set, a Random Forest ($100$ estimators) was trained on the source domain and evaluated both in-domain (untouched holdout partition) and cross-domain (unseen external dataset):

| Transfer Direction | Source Domain | Target Domain | In-Domain Macro-F1 | Cross-Domain Macro-F1 | Generalization Drop (%) |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **CIC $\to$ UNSW** | CIC-IDS2017 | UNSW-NB15 | $\approx 0.98$ | $\approx 0.58 - 0.65$ | **$-33.7\%$ to $-40.8\%$** |
| **UNSW $\to$ CIC** | UNSW-NB15 | CIC-IDS2017 | $\approx 0.96$ | $\approx 0.52 - 0.60$ | **$-37.5\%$ to $-45.8\%$** |

### Key Scientific Takeaways:
1. **The In-Domain Illusion**: High in-domain performance ($>96\%$) creates a false sense of security. The model has partially memorized the background traffic artifacts of the specific network testbed.
2. **Asymmetric Sensitivity**: Models trained on synthetic traffic generators (UNSW IXIA) transfer poorly to behavioral user traffic (CIC B-Profiles) due to missing background user noise.
3. **Feature Fragility**: Packet rate and byte rate features drift dramatically between networks. Ratios (e.g. forward-to-backward packet ratio, TCP flag proportions) demonstrate substantially higher cross-domain stability than raw volumetric counts.

## 5. Architectural Recommendations for Production Deployment

To mitigate cross-dataset degradation in real-world environments:
1. **Unsupervised Domain Adaptation (UDA)**: Align feature representations in a shared latent space using Maximum Mean Discrepancy (MMD) or domain-adversarial neural training (DANN).
2. **Local Baseline Calibration**: Before activating enforcement mode, calibrate local benign traffic medians for 48 hours to establish site-specific baseline distributions.
3. **Ensemble Blending**: Combine supervised flow classifiers with unsupervised anomaly detectors (Isolation Forest) to flag flows whose feature distributions diverge from the training manifold.
